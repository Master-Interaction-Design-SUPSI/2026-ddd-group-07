---
title: How far can you drive on the electricity of 1,000 AI prompts?
authors: Jennifer Ji, Victoria Mezo
---

**Generative AI** feels weightless, yet every answer to a text prompt is computed on physical chips, **GPUs** [[GPU]] [[GPUs|Graphics processing units: chips built to run many calculations in parallel, now the main hardware behind AI.]], that draw electricity from the grid. We look at the electricity of **AI inference** [[inference|Using a model that has already been trained, for example asking a chatbot a question. Training the model in the first place is a separate energy cost.]]: the energy spent every time a model is used. It connects to the Materialities of AI [[Crawford, 2021. Atlas of AI|https://yalebooks.yale.edu/9780300264630/atlas-of-ai|type=bibliography]] through its most direct material input, **electricity**, and the hardware and data centres behind it.

*How far could an electric car drive on the GPU electricity that different AI models need to answer the same 1,000 prompts?*

To find out, we used the [Hugging Face AI Energy Score](https://huggingface.co/spaces/AIEnergyScore/Leaderboard), which tested 62 open text-generation models [[open models|Models whose files are published, so anyone can run and measure them. Closed models such as ChatGPT cannot be measured this way.]] with the same 1,000 prompts on the same hardware, with reasoning turned off [[reasoning off|Some models can first write out hidden intermediate steps before answering. This mode was switched off so that every model does the same task, since it usually takes much more electricity.]], and measured each in **kWh** [[kWh|Kilowatt-hours, the unit on an electricity bill. 1 kWh is a 1,000-watt appliance running for one hour.]] of GPU electricity. We converted each value into kilometres for an electric car using 20.7 kWh per 100 km [[km formula]] [[Weiss et al., 2024. Energy Consumption of Electric Vehicles in Europe|https://doi.org/10.3390/su16177529|type=bibliography]] and sent every car down the same real road, from Mendrisio [[Mendrisio station]] to Lugano along the lake, 18.4 km long (route computed with OSRM on [OpenStreetMap](https://www.openstreetmap.org) data). The cars end up far apart. The most demanding model, Command R+, drives {crimson|16.55 km} and stops 1.85 km before Lugano [[Lugano]], while the lightest, distilgpt2, moves {crimson|6.3 m}, just over one car length: a {crimson|2,609-fold} difference for the same task. Most cars barely leave the station, as 51 of the 62 models stop within the first 400 m. **Model size** explains much of this gap. The AI Energy Score sorts models by their number of parameters [[parameters|The numbers a model adjusts while learning. More parameters means a bigger model that needs more computation for each answer.]] into class A (up to 20 billion), B (up to 66 billion) and C (more than 66 billion) [[model classes]] [[Hugging Face, 2025. AI Energy Score documentation|https://huggingface.github.io/AIEnergyScore/|type=bibliography]], and almost all the cars that drive far are class C. Yet size is not the only factor, since some large models use much less: the same request can cost very different amounts of electricity depending on which model answers it. These distances are calculated equivalents, not real trips, and they count only the GPU, not the cooling or the rest of the data centre, so the real consumption of every answer is higher.
